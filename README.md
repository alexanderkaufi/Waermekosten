# Wärmekostenrechner – Websiteentwurf

Responsive GitHub-Pages-Projektvorschau für eine Wärmekostenrechner-Seite im Stil des EBF-Webauftritts. Der Entwurf enthält die bereitgestellte Hero-Grafik, eine EBF-inspirierte Kopf- und Fußzeile, den lokalen Kostenvergleich, Erläuterungen und FAQ.

## Inhalt

- `index.html`: komplette statische Seite mit responsive Navigation und Rechner
- `assets/themenbild-waermekosten.png`: von Alex bereitgestelltes Themenbild oberhalb des Seitentitels
- `assets/ebf-logo.svg`: EBF-Logo aus dem öffentlichen EBF-Auftritt

Die Rechnerfelder werden nur im Browser verarbeitet. Es gibt kein Kontaktformular und keinen externen Berechnungsdienst. Beispielwerte sind änderbare Modellannahmen. Die Berechnung bildet weder eine individuelle Energieberatung noch das EWI-Wärmekosten-Tool ab; Details und Grenzen stehen direkt auf der Seite. Rechtliche Links führen derzeit zu den entsprechenden Seiten des EBF-Webauftritts und sind noch keine eigenen Rechtstexte für eine spätere Veröffentlichung.

## Vorschau

Die Vorschau ist unter <https://alexanderkaufi.github.io/Waermekosten/> erreichbar. GitHub Pages veröffentlicht den Stammordner des Branches `pages-preview` aus dem bestehenden Repository. Da das Repository öffentlich ist, ist auch die Website öffentlich erreichbar.

Die separate Produktionswebsite bleibt unverändert. Die fachliche Abnahme, Prüfung weiterer Bildschirmgrößen und die Zuordnung eigener Rechtstexte für eine spätere Verwendung stehen noch aus; Details stehen in `design-qa.md`.
